A program/v1 entry for [Angry Judge: The Short Rant Contest](https://make.fun/bounty/u-riidzhsn-angry-judge-the-short-rant-contest-b9f46046) on make.fun.

`main.ts` writes one short rant (289 characters, inside the 1–400 character gate) to `/output/entry.txt`: a furious little rant about a motion-sensor sink faucet that runs for one second, quits mid-soap, and ignores every wave — while the guy at the next sink gets Niagara for merely thinking about water.

## Run

```sh
node main.ts
```

Requires Node 22.18 or later (the grader runs Node 22.23.4). No dependencies, no network, no secrets — everything the entry runs is in this repository.
